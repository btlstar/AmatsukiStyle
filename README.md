# AmatsukiStyle · 天月本地装扮

天月麻雀 Windows 客户端的独立本地装扮插件，提供游戏目录选择、启用 / 停止连接与游戏启动窗口。首版 **0.1.0** 以预发布版提供。

从 [Releases](https://github.com/btlstar/AmatsukiStyle/releases/tag/v0.1.0) 下载 `AmatsukiStyle-0.1.0-windows-x64.zip`，完整解压后运行 `AmatsukiStyle.exe`。随包包含 Python 和依赖，无需代理或证书。

## 使用

1. 正常安装天月麻雀并完成官方更新。
2. 打开工具，选择包含 `mahjongP.exe` 的安装目录。
3. 点击「启用装扮」，正常启动并登录游戏；也可以点击「启动游戏」并自动开始连接。
4. 保持工具窗口运行，在游戏原有界面选择雀士、造型、装扮与套组。
5. 需要停用时点击「停止连接」，再重新启动游戏，恢复官方显示。

游戏启动与登录期间会显示等待状态。游戏重新启动后自动连接；登录大厅后自动恢复上次选择的雀士与背景，无需进入雀士页重新切换。同一游戏只需启用一个装扮工具，重复连接会显示原因。

## 功能范围

- 雀士、皮肤、星标、头像框、称号与名片装饰。
- 背景、手部、立直棒、牌面、牌背、桌面、特效、音乐及表情。
- 大厅、对局和表情套组的本地保存与使用。
- 好感度和觉醒相关的语音、表情及演出本地预览。
- 自身友人房资料和牌桌装扮同步，其他玩家资料保留。

只改变本机显示，不增加服务器拥有物，不修改真实购买、货币、好感度、觉醒进度或奖励，也不保证其他玩家视角可见。客户端更新后可能需要重新适配；本工具不提供 AI 建议或自动操作。

## 本地资料与恢复

- 本地装扮选择按账号保存在 `%LOCALAPPDATA%/AmatsukiStyle/profiles`，不保存登录凭据。
- 窗口只在 `%LOCALAPPDATA%/AmatsukiStyle/gui.json` 记住所选游戏目录。
- 不替换游戏文件；停止工具并重新启动游戏即可恢复官方显示，本地选择仍保留。
- 资源定义从所选客户端安装目录读取，发布包不包含游戏资源、个人配置、日志或开发记录。

## 从源码运行与构建

使用 Windows x64、Python 3.12，安装 `requirements.txt` 后运行 `python gui.py`。命令行入口为 `python host.py "包含 mahjongP.exe 的目录"`。

构建便携包时安装 `requirements-build.txt`，再运行 `python package.py`。完整依赖锁定见 `requirements-lock.txt`。发布包包含项目与第三方依赖许可、文件摘要清单和 ZIP 的 SHA-256 校验文件。
