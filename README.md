# AmatsukiStyle · 天月本地装扮

面向天月麻雀 Windows 客户端的独立本地装扮插件。当前为开发原型，尚未发布稳定版。

范围包括角色与造型、头像框与称号、背景、手部、立直棒、牌面与牌背、桌面、特效、音乐、表情及名片装饰，以及大厅、对局和表情套组的本地保存。好感度、觉醒相关的语音和表情仅调整本地预览，不改变账号真实养成或奖励。

## 源码运行

使用 Windows x64、Python 3.12 安装 `requirements.txt`。正常启动天月并登录后，运行：

```text
python host.py "包含 mahjongP.exe 的游戏目录"
```

插件通过当前进程提供本地装扮适配，不替换游戏文件。保持工具运行，在游戏原有界面选择装扮；退出游戏后连接结束，下次登录需重新运行工具。当前仍需验证部分界面与进桌流程，暂不用于正式对局。

本地选择按账号分别保存在 `%LOCALAPPDATA%/AmatsukiStyle/profiles`；仅包含装扮选择和套组，不保存登录凭据。还原默认显示时，停止工具并重新启动游戏。

游戏资源从所选安装目录读取，不随源码分发。代码采用 [Apache-2.0](LICENSE.txt)，来源与依赖许可见 [NOTICE](NOTICE)。
